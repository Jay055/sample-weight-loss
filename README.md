# Sample Weight Loss

A static prototype for a premium medical weight-management storefront.

## Prototype flow
- White and nude visual system
- Treatment option cards with expandable information
- Short assessment for height, weight, goal and activity
- Responsible result directing users to a healthcare professional
- Product section designed to map to Shopify products
- No backend required for this prototype

## Deployment
This project is static and can be deployed directly on Vercel. Import this GitHub repository into Vercel with the default settings.

## Important
Prototype only. Medical, medication, eligibility, safety and regulatory content must be reviewed and approved by appropriate qualified professionals before production use.
